  `frontend/tools/run-batch/main.js:672-677`.

  `frontend/config/toolDefinitions.js:1-65`; plan 008 only defers action-only
  dependencies inside lazy tool chunks.

  plan 002 addresses the current post-optimization GridView render path only.

  defer until that investigation exists.

  local generated artifact during the audit, so cache policy needs deployment
  verification before a safe plan is written.
- Alternate Compare Config Vertical Card and Master Detail views: their
  all-record rendering is a separate UX decision and is not changed by plan 002.
